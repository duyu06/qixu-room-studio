# 栖序 Qixu → Coohom 功能对标矩阵
核对日期：2026-10-22。**当前 NOT FULL PARITY / 尚未达到完整 Coohom 功能。**

## 目标与依据
目标是独立实现可对标 Coohom 的家装设计、准确建模、材质、渲染与交付能力，
不复制 Coohom UI 素材、品牌商标、模型库或专有源码。

官方证据：
- https://www.coohom.com/enterprise/floor-planner（2D/3D、模型库、16K/360 漫游）
- https://open.coohom.com/helpcenter/（CAD、楼层、渲染、项目导出、团队）
- https://www.coohom.com/helpcenter/3FO4K4UMM3MT（定制柜体、参数化建模、施工图与 CAM）
- https://www.coohom.com/helpcenter/floor-plan-generate-a-smart-layout-with-ai-layout-tool（AI 空间布局）
- https://www.coohom.com/helpcenter/2026-june-july-product-update-new-live-rendering-tool%2C-design-and-render-simultaneously（实时光照）

## 对标现状
状态：**已验证**=有自动测试/通过 PR；**实验**=基本实现但缺专项证据；**缺失**=尚未实现。

|Coohom 能力|栖序现状|验收差距|
|---|---|---|
|精确户型线段绘制|已验证：米制、端点拖动、吸附与撤销|复杂曲线、约束角度、双层墙仍缺|

## 商用停止门槛（不得提前宣布完成）
1. Coohom 对标项目和功能矩阵中的 P0/P1 均有可用产品能力，不接受用假按钮代替；
2. 100 份来源合法的真实户型，DXF/DWG/PDF/照片输入有定量误差及人工校准验收；
3. 同一项目在电脑/移动设备完成编辑、保存、导出、再次导入与多人版本协作；
4. 客户授权的家具模型、材质、合法许可条款和可查询素材系统；
5. GPU 渲染真机/场景基准，异步队列支持断点、重试、渲染成本控制；
6. 真实商业安全、隐私条款、组织权限、持续监控、配额、灾备；
7. 第三方安全/性能检查与主流浏览器、移动设备回归；
8. 任何未校准 CFD / 光照结果有清晰科学限制声明，不能冒充建筑认证报告。
