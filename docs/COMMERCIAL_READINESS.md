# 栖序 Qixu · 商用就绪评审 (2026-10-22)

**总体结论：NOT READY FOR PAID/ENGINEERING USE。**
当前适合作为交互式原型或限定测试。Render Live 仅说明静态资源发布成功，不证明 WebGL/WebGPU、户型建模、物理精度或数据安全合格。

## P0 阻断项
| 类别 | 现状 / 风险 | 验收标准 |
|---|---|---|
| 户型准确性 | OCR/视觉识别仍是黑白墙线启发式提取；仅 K4 已知模板手工标注，其他图片可能漏墙、误墙 | 至少 20 个真实合法来源户型，人工对照标注和相应容差；未标尺时强制显示“示意比例” |
| 图片来源与权限 | 用户户型图可能含住所信息，存储在浏览器 localStorage | 隐私告知、数据删除、跨域依赖风险审查与渗透测试通过 |
| 3D 端到端 | 尚缺真实 Chrome/Edge/移动设备完整测试；Playwright 基础自动化刚建立 | 桌面及移动端导入/旋转/移动/保存/恢复/导出成功，关键 JS 错误=0 |
| 科学计算 | CFD 为二维势流/相对示踪，未测风压温差，不是 OpenFOAM 工程求解 | 不宣传真实风量；若提供工程数值，要求封闭网格验证、守恒、收敛、独立样本实测对照 |
| 光学计算 | WebGPU 路径追踪为实验预览，缺设备矩阵；用户需校准经纬度、真北和窗洞 | WebGPU 有效渲染及降级可用；真实日照用途需朝向/遮挡/材料/窗高校准和基准测试 |
| 商业合法性 | 用户协议、隐私政策、服务支持、版权/素材许可清单未完善 | 法务与安全审查，提供数据处理规则、免责声明、第三方库许可台账 |
| 性能与容量 | 尚无 100+ 家具/复杂 80+ 墙体的长时稳定性测量 | 性能基准：典型桌面目标 30 FPS，操作 p95<150ms，10分钟内无明显内存持续增长 |
| 发布质量 | 旧 CI 只有纯逻辑与语法测试；新 PR 引入 Playwright | PR 验收 + 人工真实浏览器 + 自动回归 + Render 部署记录 |

## P1 可售版本 MVP
1. **CAD/BIM 友好**：导入 DXF/SVG（后续 IFC），房间尺寸/墙厚/门窗框可编辑、自动测量校准。
2. **真实编辑体验**：墙线对齐、选中态、吸附、对齐、撤销重做、预览版本历史，导出 GLB/PNG/JSON。
3. **自托管依赖**：固定 three.js、SunCalc、路径追踪库版本，Vite 构建锁文件，消除线上 CDN 单点故障与第三方 JS 对本地数据的访问风险。
4. **数据与后台**：匿名本地使用与账号云同步明确分界，身份认证、加密、访问控制、删除/导出数据与审计日志。
5. **运维**：错误监控、Release tag、回滚、接口限流、项目配额、SLO 与故障说明。

## P2 工程仿真（独立可选服务）
- OpenFOAM 单独容器与受限 CPU/内存队列；生成封闭几何和网格，`checkMesh` 通过后进行求解。
- 需要真实室外工况、开口压力边界和测量值；显示仿真状态、网格质量、收敛残差和置信范围。
- 未完成现场验证前，交付“可视化方案”而非“经认证的建筑气流/风水科学结论”。

## 发布策略
- `main` 是 Render 自动部署的生产分支；Loop 修复先进 PR。
- CI 失败、WebGL 失败、未验证数据泄露风险时禁止合并。
- 每次迭代附自动测试、截图/录屏、测试机型与风险清单。
- 后台费用、商业协议、托管变更需用户明确决定。

## 风水功能界定
八卦方位、五行文化属于民俗文化信息层。压力场与光线路径是真实数学/物理近似，其可信程度由输入与求解器决定。不得混淆风水文化粒子与测量地磁场/实际风场，也不得用吉凶承诺代替可验证的建筑设计要求。
