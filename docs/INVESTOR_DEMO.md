- 专属产品页：/showcase.html
- 3D 样板间：/studio.html?template=sunlit&view=3d
- 原始专业工作台：/studio.html
- 研究实验室：/index.html

## 现场五分钟演示（实际功能，不是幻灯片）
1. 打开产品页，向投资人介绍栖序的定位：浏览器中的户型设计和空间可视化工具。
2. 在三套可编辑样板间中选择“日光都市公寓”，点击立即进入 3D。说明全部房间使用同一套实际米制对象数据，不是预渲染图片。
3. 切回 2D，选择沙发并拖动，修改尺寸，观察几何与房间检测变化，再切到 3D 演示。也可点击墙段添加门/窗，实体模型会留孔。
4. 展示 DXF 墙线导入/导出、工程量清单、第一人称漫游、项目 JSON 备份。
5. 回到展示页，点明下一阶段：真实 GLB 家具、PBR 材质、云项目协作、收费渲染服务和行业素材生态。

## 准确定位
当前为可运行早期产品，未达到 Coohom 功能完全对等，更没有 750 万付费模型、16K 云渲染或经认证的工程 CFD。展示页中所有样板间是程序生成的可编辑项目（不是 Coohom 授权素材）。不得虚构收入、客户数量、签约订单或 GPU 渲染性能。

## 需要收集的投资证据（不要臆造）
- 用户实测：首次完成户型设计用时、成功率、任务放弃点、留存。
- 最低可验证性能：高端/主流集显桌面浏览器启动耗时、复杂户型帧率、导出/恢复成功率。
- 商业化：真实访谈/意向书、付费意愿、愿意承担的渲染费用、每次模型加载与渲染成本。
- 市场路径：室内设计工作室 → 装修公司 → 家具制造商，优先验证单一客群付费。
- 安全合规：版权、隐私、用户方案备份、正式商用许可台账。
