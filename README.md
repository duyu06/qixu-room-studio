# 栖序 Qixu · 3D 风水装修设计实验室

使用 Three.js、原生 JavaScript 和 CSS 构建的浏览器端室内空间设计器，支持家具布置、采光示意、后天八卦方位与传统文化流场效果。

## 部署到 Render

使用仓库根目录的 `render.yaml` 创建 Static Site。或手动选 **New → Static Site**，Build Command 填 `echo "Static site: no build required"`，Publish Directory 填 `site`。

## 特别说明

- 风水「气场」为传统文化可视化，不是实测物理磁场。
- 房间尺寸与太阳位置需要用户校准，估算不替代建筑测绘。
- 照片仅在当前浏览器处理；请导出 JSON 备份方案。
- Three.js 通过 CDN 加载，首次使用需联网。

仓库用于保存栖序 V4 的源码、测试和持续迭代记录。

## V5：整屋联通布局

- 客厅居中、书房在左、卧室在右，三间共享一整块连续地面与外墙，隔墙上有真实通行门洞。
- 取消墙面展开模式；房间不会拆开或单独浮动。切换客厅/卧室/书房仅切换当前编辑目标，不移除其他房间家具。
- 家具只能在所属房间内摆放，长宽与旋转会参与边界检查；“重置当前房间”不会影响其他房间。
- 保存方案采用 `qixu-room-v5`，能读取旧版 V1–V4（旧家具迁移到对应房间）。
- 现有光照覆盖率、青色动线计算仍主要针对中央客厅，不代表整屋采光或疏散验证。

## V7 可视化升级

- 户型图地板纹理保持原始色彩，不再叠加灰色半透明墙材质。
- 暖白剖切（默认 1.22m）、真实立面（2.52m）、轻透墙三种可切换墙体视觉，墙线保持连续。
- 日光时间（06:00–20:00）、暖色光斑、方向光与柔和投影、夜间暖灯场景。
- 独立作用于**导入户型**的动态后天八卦圆环、五行色彩粒子、八方汇聚流场，可开关并随现有速度和粒子密度设置变化。
- 日光仅为艺术参考，户型图未标注真实窗位/朝向/城市，不能作为施工采光报告；风水粒子不代表真实磁场或空气流动。

## V8 实验性物理模拟

- 以门口为较高压力边界、窗户为较低压力边界，求解二维拉普拉斯压力势场 `∇²p = 0`。实体墙与家具栅格化为固体障碍，固体边界采用无穿透通量；沿压力梯度求相对速度，并输运示踪粒子。
- K-4 示例默认门口在东侧开口，窗口在北侧；**必须在俯视图手动确认并重新标记**，尤其是公共楼梯的入口与真实室内门不同。
- 这是物理约束的二维稳态无旋流基线，不是三维不可压 Navier–Stokes CFD，也不含真实风压、温差、湍流或实测风速；气流速度只标相对量。彩色粒子仅用于显示数值结果。
- 天文太阳方向通过 SunCalc 2.1.1 计算；UI 提供纬度/经度、日期、时区，默认北京**演示**数据，不是自动识别用户位置。Three.js 用方向光与 shadow map 根据模型墙体投影；尚无准确窗台高度与外部遮挡模型。
- 项目实现独立于 GitHub 示例仓库，无直接复制第三方代码。参考：Jos Stam《Stable Fluids》、PavelDoGreat/WebGL-Fluid-Simulation、mharrys/fluids-2d、mourner/suncalc。
